firedev redesign showcase

5 landing page variants. Radically different designs, same brand.

VARIANT 1 DARK MONOSPACE

The Brutalist Terminal

Trust angle. Looks like an actual terminal session — prompts, git log, brew list. Zero decoration, raw confidence. For CTOs who respect craft over marketing.

→
VARIANT 2 DARK ANIMATED

The Speed Machine

Speed angle. Animated gauge, diagonal cuts, timeline bar chart comparison. CSS-only conic-gradient speedometer. Startup launch energy.

→
VARIANT 3 LIGHT SERIF

The Swiss Anti-Agency

Solo unicorn angle. Light theme, serif typography, real HTML comparison table vs 5-person agency. Massive whitespace. The anti-template.

→
VARIANT 4 DARK PARTICLES

Burn the Backlog

Fire maximalist. CSS ember particles, provocative copy, "incident report" social proof. Warm color system. The one that takes risks.

→
VARIANT 5 DARK README

The README

Developer-to-developer. GitHub dark mode aesthetic, git diff coloring, YAML syntax highlighting, FAQ. Reads like technical docs, not marketing.

→

Design matrix

# Theme Type Target Angle
1 Dark Monospace / Terminal Senior engineers, CTOs Trust + craft
2 Dark Kinetic / Animated Startup founders Speed + urgency
3 Light Swiss / Serif Cost-conscious buyers Value + efficiency
4 Warm dark Maximalist / Particles Engineering managers Action + provocation
5 GitHub dark README / Docs Developers Technical credibility

Research-backed positioning:

  • Trust is the #1 buying objection for AI-powered services (variants 1, 5)
  • Speed is the most visceral top-of-funnel hook (variant 2)
  • "One-person unicorn" is the defining narrative of 2026 tech (variant 3)
  • Provocative copy outperforms safe copy for differentiation (variant 4)
  • Developer-native communication converts better than marketing-speak (variant 5)
