matrix

Open source · Terminal

Matrix rain screensaver for the terminal. For recording livestreams.

Matrix rain screensaver for your terminal. Press any key - it launches whatever you tell it to.

Film-style halfwidth katakana, white-hot drop heads, green gradient trails, three parallax depth layers, and rain intensity that ebbs and flows like real weather.

cmatrix has no katakana. This one does. Wake up, Neo.

Install

Homebrew

brew install firedev/tap/matrix

Single file

curl -o /usr/local/bin/matrix https://raw.githubusercontent.com/firedev/matrix/master/matrix
chmod +x /usr/local/bin/matrix

Use

matrix claude    # rain falls… any key → claude starts on a clean screen
matrix           # just the rain, any key to exit

Stack

Python 3 · stdlib only · Homebrew
