threefinger

Three-finger trackpad swipe to switch browser tabs on macOS.

Swipe left or right with three fingers to jump to the previous or next tab. Default shortcut is Ctrl-Shift-Tab / Ctrl-Tab, so it works in Safari, Chrome, Firefox, and most tabbed apps.

A tiny open-source Swift utility that replaces that one BetterTouchTool feature - one file, MultitouchSupport, Karabiner-style config in ~/.config/threefinger.json.

Install

Install, allow threefinger when Settings asks, free the left/right swipe for tabs - keep three-finger up/down for windows.

Homebrew

brew install firedev/tap/threefinger
brew services start threefinger

Installer script

curl -fsSL https://raw.githubusercontent.com/firedev/threefinger/master/install.sh | bash
  1. Run threefinger --check --open and turn on Accessibility and Input Monitoring for threefinger (not Terminal).
  2. In Trackpad → More Gestures, set Swipe between full-screen applications to Swipe Left or Right with Four Fingers. Swipe between pages → Off is optional but nicer.
  3. Keep Mission Control and App Exposé on three fingers. Then: up = all windows, down = this app’s windows, left/right = previous/next tab.
Three fingers Does
↑ All windows (Mission Control)
↓ Windows for this app (App Exposé)
← Previous tab
→ Next tab

If something's stuck

Permission Without it
Accessibility Swipes work, but tabs never change
Input Monitoring Trackpad gestures never arrive

After an upgrade, remove threefinger from Accessibility (−) and add it again - toggling is not enough. Homebrew path: /opt/homebrew/opt/threefinger/bin/threefinger. curl installer: ~/.local/bin/threefinger.
